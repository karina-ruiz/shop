# ☕ Shop – Tienda de café en línea

## 📌 Descripción
**Shop** fue uno de mis primeros proyectos de prueba, creado para explorar y fortalecer mis habilidades en desarrollo web con Django.  
La aplicación simula una tienda de café donde el usuario puede realizar pedidos mediante un formulario, y estos se almacenan para que el encargado los prepare.

Aunque es un proyecto sencillo, fue clave para aprender sobre formularios, flujo de datos y diseño limpio.

## ⚡ Funcionalidades
- 📝 Formulario de pedido personalizado.
- 📥 Almacenamiento de órdenes en base de datos.
- 👨‍🍳 Visualización de pedidos para el encargado.
- 🧼 Código estructurado y legible.

## 🛠️ Tecnologías utilizadas
- Django `5.1.1`
- Pillow `10.4.0`
- Crispy Tailwind `1.0.3`
- Django REST Framework `3.15.2`

## ⚙️ Instalación y uso
1. Clona el repositorio:  
   ```bash
   git clone https://github.com/karina-ruiz/shop.git
   ```

2. Ingresa a la carpeta del proyecto:  
   ```bash
   cd shop
   ```

3. Instala las dependencias:  
   ```bash
   pip install -r requirements.txt
   ```

4. Ejecuta el servidor local:  
   ```bash
   python manage.py runserver
   ```

5. Abre tu navegador en `http://localhost:8000` para comenzar a usar la app.
